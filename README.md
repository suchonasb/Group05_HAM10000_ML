## 🎯 Project Overview

This repository contains the course project for **Track 2: Graph Convolutional Network (GCN)**.

The objective of this project is to classify skin lesions from dermoscopic images using a **Graph Convolutional Network (GCN)** by transforming images into graph representations.

---

## 📂 Dataset

**Dataset:** HAM10000 (Human Against Machine with 10,000 Training Images)

- **Application:** Skin Lesion Classification
- **Data Type:** Dermoscopic Images
- **Number of Classes:** 7
- **Track:** Track 2 – Image to Graph using GCN
